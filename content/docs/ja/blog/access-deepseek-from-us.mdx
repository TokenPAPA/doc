## 方法 2：DeepSeek に直接登録する

直接利用したい場合の公式登録手順は以下のとおりです — ただし 2025 年時点では依然として検証に中国の電話番号が必要です。

### ステップ 1：DeepSeek のプラットフォームにアクセス
[platform.deepseek.com](https://platform.deepseek.com) にアクセスし、「Sign Up」をクリックします。

### ステップ 2：中国の電話番号で検証
DeepSeek は +86 番号での SMS 検証を要求します。お持ちでない場合は、ここで行き詰まります。

### ステップ 3：API キーを生成
登録が完了したら、API Keys セクションに移動して新しいキーを作成します。

### ステップ 4：リクエストの送信を開始
```python
from openai import OpenAI

client = OpenAI(
    api_key="your-deepseek-api-key",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

> **注**：直接登録の支払いは中国の決済手段を通じた人民元建て — 米国の開発者にとってもう一つの障壁です。

## よくある質問

### 米国から DeepSeek API を使うには中国の電話番号が必要ですか？
**API リレープラットフォームを使う場合は不要です。** DeepSeek プラットフォームでの直接登録には +86 番号が必要ですが、リレーサービスがその側で登録を処理するため、通常のメールでサインアップし、米国のクレジットカードで支払えます。

### 米国で DeepSeek API を使うのは合法ですか？
はい。DeepSeek の API を使うこと、またはリレープラットフォーム経由でアクセスすることは合法です。DeepSeek のモデルはオープンウェイトであり、寛容なライセンスの下で提供されています。API の利用に輸出規制は適用されません。

### DeepSeek を OpenAI の代わりに使うとどれくらい節約できますか？
DeepSeek V3 は GPT-4o のおよそ **10〜20 分の 1 の安さ**です。毎月 1000 万 tokens を処理する典型的な開発者の場合、おおよそ **GPT-4o で月約 $300 に対し、リレープロバイダー経由の DeepSeek で月約 $15〜30** です。

### DeepSeek と GPT-4o の品質差はどの程度ですか？
DeepSeek V3 は、特にコーディングと推論のタスクで、ほとんどのベンチマークにおいて GPT-4o と互角の性能を発揮します。DeepSeek R1 は複雑な推論で OpenAI o1 に匹敵しながら、はるかに安価です。多くの本番ユースケースでは、品質差は無視できる程度です。

### DeepSeek API を LangChain などのフレームワークで使えますか？
はい。リレープラットフォームは OpenAI 互換エンドポイントを提供するため、DeepSeek は LangChain、LlamaIndex、Vercel AI SDK、そして OpenAI の API 形式をサポートするあらゆるツールとシームレスに連携します。
