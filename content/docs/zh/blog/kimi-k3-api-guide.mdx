## 流式输出

```python
from openai import OpenAI

client = OpenAI(base_url="https://tokenpapa.ai/v1", api_key="你的 TokenPAPA Key")

stream = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "写一首关于人工智能的五言诗。"}],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```
