## 第 1 步 —— 安装与配置

```bash
npm i ai @ai-sdk/openai
```

创建 `.env.local` 文件:

```bash
DEEPSEEK_API_KEY=your-tokenpapa-key
```

去 [tokenpapa.ai](https://tokenpapa.ai) 拿 Key——注册即送 **$1 免费额度**,不需要信用卡。

---

## 第 2 步 —— 创建路由处理器

`app/api/chat/route.ts`:

```ts
import { streamText } from 'ai';
import { createOpenAI } from '@ai-sdk/openai';

const openai = createOpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: 'https://tokenpapa.ai/v1', // OpenAI 兼容
});

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: openai('deepseek-v4-flash'),
    messages,
  });
  return result.toDataStreamResponse();
}
```

后端就这么点代码。`streamText` 帮你处理 token 流式、取消和错误。

## 第 3 步 —— 用 useChat 构建聊天界面

`app/page.tsx`:

```tsx
'use client';
import { useChat } from 'ai/react';

export default function Chat() {
  const { messages, input, handleInputChange, handleSubmit } = useChat();

  return (
    <div style={{ maxWidth: 640, margin: '0 auto', padding: 24 }}>
      {messages.map(m => (
        <div key={m.id}>
          <strong>{m.role === 'user' ? 'You' : 'DeepSeek'}:</strong> {m.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Ask anything…"
          style={{ width: '80%', padding: 8 }}
        />
        <button type="submit">Send</button>
      </form>
    </div>
  );
}
```

`npm run dev` 跑起来,一个流式聊天就上线了。V4 Flash 首 token 大约 **0.4s** 就能到。
