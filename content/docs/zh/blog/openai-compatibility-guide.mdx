如果你在 2026 年用过大模型 API，那你一定用过 OpenAI 的格式。`/v1/chat/completions`、`messages` 数组、`model` 字符串、`role`/`content` 结构——这已经成了事实标准。

## 什么是 OpenAI 兼容 API？

一个 API 被称为 "OpenAI 兼容"，意味着它使用完全相同的：

- **端点**：`/v1/chat/completions`
- **请求体**：`{ model, messages, temperature, max_tokens, stream }`
- **响应格式**：`{ id, object, choices: [{ message: { role, content } }], usage }`
- **认证方式**：`Authorization: Bearer <key>`
- **流式输出**：基于 SSE 的 `text/event-stream`，使用 `data: {...}` 增量

```python
# 这段代码对任何 OpenAI 兼容的供应商都有效
import requests

response = requests.post(
    "https://api.openai.com/v1/chat/completions",  # ← 改这里
    headers={
        "Authorization": "Bearer <key>",  # ← 改这里
        "Content-Type": "application/json"
    },
    json={
        "model": "gpt-4o",  # ← 改这里
        "messages": [{"role": "user", "content": "你好！"}],
        "temperature": 0.7
    }
)
```

改掉 **base URL**、**API Key** 和 **model 名称**——你就切换到另一个完全不同的厂商了。

## 高级用法

### 1. 成本优化路由

简单任务用便宜模型，复杂任务用贵模型：

```python
def get_completion(complexity, message):
    model = "deepseek-v4-flash" if complexity == "simple" else "claude-sonnet-4-6"
    
    client = OpenAI(base_url="https://tokenpapa.ai/v1", api_key="your-key")
    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": message}]
    )
    return response.choices[0].message.content

# 简单问候 → $0.00003
print(get_completion("simple", "你好！"))

# 复杂分析 → $0.015
print(get_completion("complex", "分析这份财务报告..."))
```

### 2. 自动故障转移

一个供应商挂了，自动切换到下一个：

```python
def robust_completion(messages):
    models = [
        "deepseek-v4-flash",    # 先用 DeepSeek（最便宜）
        "gpt-5.4-mini",         # 降级到 GPT
        "claude-sonnet-4-6",    # 最后的保底
    ]
    
    client = OpenAI(base_url="https://tokenpapa.ai/v1", api_key="your-key")
    
    for model in models:
        try:
            response = client.chat.completions.create(
                model=model, messages=messages, timeout=30
            )
            return response.choices[0].message.content
        except Exception:
            continue
    
    raise Exception("所有供应商都挂了")
```
