## DeepSeek 为什么涨价

1. **需求激增** — DeepSeek V4 Flash 已成为全球使用量最大的模型之一，7月31日发布当天就撑满了算力。
2. **算力成本上升** — 以 $0.14/1M 输入 Token 的价格维持高流量 API 难以持续；业内人士认为缓存命中价格此前是靠补贴换市场份额。
3. **盈利压力** — 硬件和推理成本不断攀升，DeepSeek 需要走向可持续定价。

时间点耐人寻味：V4-Flash-0731 发布（7月31日）后不到一周，V4 Pro 降价 75% 几个月后，价格信号彻底反转。
