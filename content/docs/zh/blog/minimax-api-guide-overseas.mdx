## 二、MiniMax API 功能

### 文本生成（MiniMax-Text-01）
- **上下文窗口**: 最高 400 万 token（支持书籍长度的输入）
- **函数调用**: 完整的工具使用支持
- **流式传输**: 服务器发送事件（SSE），实现实时响应
- **系统提示词**: 自定义行为引导
- **多轮对话**: 对话记忆管理

### 音频生成（MiniMax-TTS）
- **声音克隆**: 上传短样本即可创建自定义声音
- **情感控制**: 可指定开心、悲伤、兴奋、平静等情绪
- **多语言**: 支持中文、英文、日文、韩文等
- **语速控制**: 调节说话速度
- **SSML 支持**: 细粒度发音控制

### 视频生成（MiniMax-Video）
- **文本转视频**: 根据文本提示生成短视频
- **图像转视频**: 将静态图片动画化
- **风格迁移**: 将视觉风格应用于生成内容
- **画面比例**: 支持 16:9、9:16、1:1

### API 访问方式
| 方式 | 说明 |
|---|---|
| **REST API** | 所有端点的标准 HTTP 请求 |
| **Python SDK** | 官方 SDK，便捷集成 |

## 八、最佳实践与速率限制

### 最佳实践

| 实践 | 建议 |
|---|---|
| **流式响应** | 聊天时始终使用 `stream=True` 以减少感知延迟 |
| **上下文管理** | 即使有 400 万 token，也请保持对话聚焦——只发送相关上下文 |
| **温度调参** | 事实性任务使用 0.3–0.5，创意生成使用 0.7–0.9 |
| **重试逻辑** | 针对 429（速率限制）和 5xx 错误实现指数退避 |
| **批量请求** | 批量处理时发送非流式请求并设置较高超时 |

### 错误处理

```python
import time
from openai import OpenAI, RateLimitError, APIError

client = OpenAI(api_key="your-key", base_url="https://tokenpapa.ai/v1")

def chat_with_retry(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="minimax-text-01",
                messages=messages
            )
        except RateLimitError:
            wait = 2 ** attempt
            print(f"Rate limited. Retrying in {wait}s...")
            time.sleep(wait)
        except APIError as e:
            if e.status_code >= 500:
                wait = 2 ** attempt
                print(f"Server error. Retrying in {wait}s...")
                time.sleep(wait)
            else:
                raise
    raise Exception("Max retries exceeded")
```
