## Kimi K3.1 Pro：3T 级开源 agentic 模型

Kimi K3.1 Pro 是月之暗面 K3.1 系列首个模型（2026-10-24 发布），官方口径为**开源权重、原生多模态的 agentic 模型**，也是目前最强的 3T 级开源模型；基于 Kimi K3 后训练并大幅强化了强化学习。

开发者关心的点：

- **上下文**：1,048,576 tokens（1M），够把整个代码库喂进去
- **输入**：支持文本、图像、视频
- **平台价**：$2.10 / $10.60（输入/输出每 1M），缓存输入 $0.21

> **关键结论**：K3.1 Pro 在 TokenPAPA 上比上一代 `kimi-k3`（$3.125/$15.62）**便宜约 33%** —— 1M 上下文的旗舰级多模态模型，价格反而更低了。

## Kimi K3.1 Pro Highspeed：高速伴生版

与 K3.1 Pro 同期发布的高速变体，面向交互式、延迟敏感的场景。

## GLM-5.3-FlashX：200 tokens/s + 1M 上下文

智谱原厂直供的高速模型，核心参数（据智谱官方与阿里云百炼文档）：

- **推理速度**：最高 **200 tokens/s**
- **上下文**：1M tokens
- **输入**：原生支持图像、视频、文件
- **平台价**：$0.32 / $1.10，缓存输入 $0.09

它比裸 `glm-5.3-flash`（$0.12/$0.42）贵一点，但比 `glm-5.3`（$1.20/$4.18）便宜约 73%，同时保留了新系列的长上下文与多模态输入。对向用户流式输出大量 token 的 Agent 产品，200 tokens/s 的体感差异非常明显。

## MiniMax M3.1 Flash：最便宜的干将

MiniMax M3.1 系列的 flash 档。刚上线公开参数还不多，从 TokenPAPA 目录可确证的是：**五款新品里最便宜**，输入 $0.16、输出 $0.63，缓存输入仅 **$0.016**（打 95 折）。

它比 `minimax-m3`（$0.328/$1.30）便宜约一半，是批量抽取、分类、摘要等高吞吐管线的新默认选项。

## Hy4：腾讯混元旗舰，首次支持视觉

Hy4 是腾讯混元新一代模型的正式版（继 `hy4-preview` 开源之后）。官方表示：预训练与后训练规模显著扩大，**首次引入视觉能力**，指令遵循、长文理解、长程任务、深度研究全面增强。

- **架构**：MoE 旗舰；preview 实测 **770B 总参数、49B 每 token 激活**，正式版规模更大
- **上下文**：超过 1M tokens
- **开源**：以开源模型发布
- **平台价**：$1.00 / $2.80，缓存输入 $0.05

Hy4 适合研究型负载：1M+ 上下文 + 原生视觉 + 开源权重，输出价格却远低于闭源旗舰。

## 该怎么选？

- **Agentic 编程 / 超长上下文** → `kimi-k3.1-pro`：1M 上下文 + 多模态 + 比前代便宜 33%

## 一行代码切换

```python
from openai import OpenAI

client = OpenAI(base_url="https://tokenpapa.ai/v1", api_key="你的KEY")

resp = client.chat.completions.create(
    model="kimi-k3.1-pro",  # 或 glm-5.3-flashx / minimax-m3.1-flash / hy4
    messages=[{"role": "user", "content": "用一句话总结。"}],
)
print(resp.choices[0].message.content)
```

开启提示词缓存后，缓存输入最低只要 $0.016/1M（M3.1 Flash），长上下文反复读取也花不了几个钱。
