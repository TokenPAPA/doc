## 如何使用

TokenPAPA 使用标准的 OpenAI chat completions 格式。如果你曾经通过 OpenAI SDK 调用过 GPT 模型，你已经会用了：

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.tokenpapa.ai/v1",    # 统一接口
    api_key="your_tokenpapa_key"                # 统一 Key
)

# 调用 DeepSeek V4 Flash
response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好！"}]
)

# 一行代码切换到 Qwen 3 Plus
response = client.chat.completions.create(
    model="qwen-3-plus",          # ← 只改模型名
    messages=[{"role": "user", "content": "你好！"}]
)
```

**就是这么简单。** 一个 base URL、一个 API Key，所有模型都能通过修改 `model` 参数来调用。

## 为什么要多模型策略？

### 1. 成本优化
不同任务需要不同模型。使用便宜模型（MiniMax T2、DeepSeek V4 Flash、Hunyuan Turbo）处理高吞吐量分类、摘要和简单生成。保留昂贵模型（Qwen 3 Max、DeepSeek V4 Pro）用于真正需要其能力的复杂推理任务。

### 2. 冗余和可靠性
当一个提供商出现故障或性能下降时，改一行代码就能切换到另一个。零停机，无级联故障。

### 3. 任务特定优势
- **代码生成**：DeepSeek Coder V2、Qwen 3 Plus
- **长文档分析**：MiniMax-01（百万上下文）、Kimi（128K+）
- **中英翻译**：混元、GLM-4
- **创意写作**：Qwen 3 Max、DeepSeek V4 Pro
- **预算批量处理**：MiniMax T2、GLM-4 Air

### 4. 地理性能
中国托管的模型在亚太地区提供更快的推理速度，同时 TokenPAPA 的优化路由确保美欧开发者也能获得有竞争力的延迟。
