# TokenPAPA 现已支持 Google 与 GitHub 一键登录

TokenPAPA 的登录方式全面升级：现在支持 **Google 与 GitHub 一键登录** —— 无需密码、无需邮箱验证码、无需等待。

一键授权即可完成登录，**首次登录自动创建账号**。一分钟后，你就能开始调用 30+ 大模型 API。

---

## 登录方式对比

| 特性 | 邮箱 + 密码 | Google 一键 | GitHub 一键 |
|------|:---:|:---:|:---:|
| **注册步骤** | 需要 | 自动创建 | 自动创建 |
| **邮箱验证** | 需要 | 不需要 | 不需要 |
| **需要记密码** | 是 | 否 | 否 |
| **首次登录耗时** | 约 2-3 分钟 | **约 10 秒** | **约 10 秒** |
| **安全性** | 密码 | OAuth | OAuth |

---

## 使用 Google 一键登录

1. 打开 [https://tokenpapa.ai/login](https://tokenpapa.ai/login)
2. 点击登录表单底部的 **Google** 图标
3. 在 Google 页面完成授权 —— 自动登录成功

就这么简单。如果是首次使用，TokenPAPA 会当场为你自动创建账号，无需单独注册、无需邮箱验证码。

---

## 使用 GitHub 一键登录

1. 打开 [https://tokenpapa.ai/login](https://tokenpapa.ai/login)
2. 点击登录表单底部的 **GitHub** 图标
3. 在 GitHub 页面完成授权 —— 自动登录成功

流程一致、速度一致，首次使用自动创建账号。

---

## 为什么开发者喜欢一键登录

- **无需管理密码** —— 少一个需要记忆的凭证
- **无邮箱验证等待** —— 立即开始使用 API
- **自动创建账号** —— 跳过整个注册表单
- **更安全** —— 标准 OAuth 授权，TokenPAPA 不会接触你的 Google/GitHub 密码
- **对开发者友好** —— GitHub 登录天然契合开发工作流

---

## 把 Google / GitHub 绑定到已有账号

已有 TokenPAPA 账号？可以绑定 Google 或 GitHub：

1. 登录后进入**个人设置**
2. 找到**第三方账号绑定**区域
3. 点击 Google 或 GitHub 旁的"绑定"
4. 完成授权 —— 账号绑定成功

绑定后即可使用一键登录，原有的 Token 和余额全部保留。

## 常见问题

**问：用 Google 或 GitHub 登录会自动创建账号吗？**
答：会。首次一键登录即自动创建 TokenPAPA 账号，无需单独注册。

**问：可以把 Google 或 GitHub 绑定到已有账号吗？**
答：可以。个人设置 → 第三方账号绑定 → 绑定即可，所有 Token 和余额不受影响。

**问：一键登录安全吗？**
答：安全。TokenPAPA 采用标准 OAuth 授权，不会获取或存储你的 Google/GitHub 密码。

## 一分钟上手

1. 打开 [https://tokenpapa.ai/login](https://tokenpapa.ai/login)，点击 **Google** 或 **GitHub**
2. 账号自动创建完成
3. 在控制台创建 **API Key**
4. 开始调用 `deepseek-v4-flash`、`gpt-5.6`、`claude-opus-4` 等 30+ 模型

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-tokenpapa-key",
    base_url="https://tokenpapa.ai/v1"
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好，TokenPAPA！"}]
)
print(response.choices[0].message.content)
```
