## 方法二：直接在 DeepSeek 注册

如果你更倾向于直连，下面是官方注册流程 —— 不过截至 2025 年它仍然需要中国手机号进行验证。

### 第 1 步：访问 DeepSeek 平台
前往 [platform.deepseek.com](https://platform.deepseek.com) 并点击 "Sign Up"。

### 第 2 步：用中国手机号验证
DeepSeek 需要用 +86 号码进行短信验证。如果你没有，就会卡在这一步。

### 第 3 步：生成 API 密钥
注册完成后，进入 API Keys 部分并创建一个新密钥。

### 第 4 步：开始发起请求
```python
from openai import OpenAI

client = OpenAI(
    api_key="your-deepseek-api-key",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

> **注意**：直接注册的付款使用人民币、通过中国支付方式完成 —— 这是美国开发者的又一道障碍。

## 如何在你的美国应用中集成 DeepSeek API
