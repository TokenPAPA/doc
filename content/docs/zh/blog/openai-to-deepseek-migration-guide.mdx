## 5. 常见陷阱与解决方案

**上下文窗口差异：** DeepSeek V3 支持 64K token（GPT-4o 为 128K）。长文本任务需要分块处理。

**推理模型行为：** DeepSeek R1 会在响应前输出 `reasoning_content`（思考过程），解析时注意过滤。

**JSON 模式：** DeepSeek 不支持 `response_format={"type":"json_object"}`，需通过 system prompt 或 function calling 实现结构化输出。

**函数调用限制：** DeepSeek R1 目前不支持函数调用，请使用 V3 处理工具调用场景。
