DeepSeek 的 API **与 OpenAI 完全兼容**,现有 OpenAI SDK 代码原样可用。整场迁移的核心,就是一个配置改动:

    api_key="sk-gpt-...",
    base_url="https://api.openai.com/v1"

    model="gpt-5.6-sol",
    messages=[{"role": "user", "content": "你好!"}]
