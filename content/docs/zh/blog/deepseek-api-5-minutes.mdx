stream = client.chat.completions.create(

## 最佳实践

1. **设置 `max_tokens`** —— 防止长输出成本失控。
2. **默认用 `deepseek-v4-flash`** —— 输入 $0.14/1M、输出 $0.42/1M;只有任务需要时才升级 `deepseek-v4-pro`。
3. **Key 放环境变量** —— 绝不硬编码在前端代码或提交到 git。
4. **善用 system prompt** —— 比在每条用户消息里重复指令更稳定。
5. **缓存重复输入** —— DeepSeek 自动上下文缓存让重复 prompt 便宜很多。
6. **处理错误** —— 429(限流)和 5xx 用指数退避重试;发送前先校验输入。

```python
import time, openai

for attempt in range(3):
    try:
        resp = client.chat.completions.create(...)
        break
    except openai.RateLimitError:
        time.sleep(2 ** attempt)   # 指数退避
```
