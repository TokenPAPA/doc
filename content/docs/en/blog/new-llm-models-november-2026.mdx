## Kimi K3.1 Pro: a 3T-class open-weight agentic model

Kimi K3.1 Pro is the first model in Moonshot's new K3.1 series, released on **2026-10-24**. According to Moonshot, it is an open-weight, natively multimodal agentic model and the most capable 3T-class model the company has released, post-trained from Kimi K3 with substantially more reinforcement learning.

Key facts for developers:

- **Context window**: 1,048,576 tokens (1M) — the full class of "give it your whole codebase" workloads
- **Modality**: accepts text, images and video, generates text
- **Family**: 3T-class open-weight, available through the Kimi API platform and aggregators like TokenPAPA
- **Price on TokenPAPA**: $2.10 per 1M input, $10.60 per 1M output, $0.21 cached input

> **Key takeaway**: Kimi K3.1 Pro is priced at roughly **33% below the previous kimi-k3** ($3.125 / $15.62) on TokenPAPA, which makes a 1M-context multimodal agentic model meaningfully cheaper per token than the generation it replaces.

## Kimi K3.1 Pro Highspeed: the low-latency companion

Kimi K3.1 Pro Highspeed is the faster companion variant announced alongside K3.1 Pro. It targets interactive and latency-sensitive workloads where the extra output speed is worth a premium.

| Comparison | kimi-k3.1-pro | kimi-k3.1-pro-highspeed |
|---|---|---|
| Input / 1M tokens | $2.10 | $4.10 |
| Output / 1M tokens | $10.60 | $21.30 |
| Best for | Deep reasoning, agentic loops, multimodal | Interactive chat, fast code completion, latency-first APIs |

If your workload is dominated by long agentic loops where correctness matters more than wall-clock speed, the standard Pro is the better value. If you are building a chat product where users feel every second, Highspeed earns its premium.

## GLM-5.3-FlashX: 200 tokens/s with 1M context

GLM-5.3-FlashX is Zhipu's high-speed model, supplied directly by Zhipu AI. The headline numbers, per Zhipu and Alibaba Cloud Model Studio documentation:

- **Inference speed**: up to **200 tokens/s**
- **Context**: 1M tokens
- **Input**: natively accepts image, video and file input
- **Price on TokenPAPA**: $0.32 per 1M input, $1.10 per 1M output, $0.09 cached

This is the "flash but faster" tier: more expensive than the bare `glm-5.3-flash` ($0.12 / $0.42) but dramatically cheaper than `glm-5.3` ($1.20 / $4.18), while keeping the long context and multimodal input of the newer line. For agents that stream a lot of tokens to the user, 200 tokens/s materially changes perceived quality.

## MiniMax M3.1 Flash: the budget workhorse

MiniMax M3.1 Flash is the flash-tier entry of MiniMax's M3.1 line. Public technical detail is still thin right after launch, so here is what is verifiable from the TokenPAPA catalog: it is the **cheapest of the five new models** at **$0.16 per 1M input and $0.63 per 1M output tokens**, with cached input at just **$0.016** — a 95% discount on cached reads.

At that price it sits below `minimax-m3` ($0.328 / $1.30) and even below most previous-generation flash models. It is the natural default for high-volume extraction, classification, summarization and any pipeline where unit economics matter more than peak quality.

## Hy4: Tencent's open-weight flagship gains vision

Hy4 is the official release of Tencent's next-generation Hunyuan model, following the `hy4-preview` open-source debut. Tencent says Hy4 significantly expands pretraining and post-training scale, **introduces vision capability for the first time**, and substantially improves instruction following, long-document understanding, long-horizon tasks and deep research.

Developer-relevant facts:

- **Architecture**: mixture-of-experts flagship; the preview measured **770B total parameters with 49B active per token**, and the official release scales further
- **Context**: exceeding 1M tokens
- **Open weight**: released as an open-source model
- **Price on TokenPAPA**: $1.00 per 1M input, $2.80 per 1M output, $0.05 cached

Hy4 is the model to watch for research-heavy workloads: the combination of 1M+ context, native vision and open weights makes it a credible alternative to the big closed flagships at a fraction of their output price.
